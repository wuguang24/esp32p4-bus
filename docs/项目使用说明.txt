一、做什么
--------------------------------------------------------------------------------
慧勤智远 ESP32-P4 上的总线通信分析仪：
  CAN(TJA1050) / RS485(TP8485E) / TTL UART / I2C / SPI
  PWM 输出 GPIO11 / ADC 采样 GPIO20
  3.5″ LVGL 触摸屏监视
  SD 卡 CSV 录制
  WiFi SoftAP + BUS1 UDP 上位机（端口 9527）

已移除：FOC 电机控制、片内以太网 DP83848。


二、启动顺序
--------------------------------------------------------------------------------
  NVS → WiFi → LVGL → bus_app → PWM/ADC init → bus_stream（UDP）


三、界面
--------------------------------------------------------------------------------
  通信 | CAN/485 | 串口 | 扩展(I2C/SPI/PWM/ADC) | 设置
  参数输入：点波特率 / PWM 频率·占空比 → 弹出数字键盘（OK 确认）


四、上位机
--------------------------------------------------------------------------------
  WiFi 连 ESP32P4-BUS / 12345678
  python tools/bus1_listen.py 192.168.4.1
  配对令牌：bus1-pair-2026


五、接线
--------------------------------------------------------------------------------
  见 docs/接线表.txt
  注意：SPI CS 已改为 GPIO12（GPIO20 专供 ADC）
